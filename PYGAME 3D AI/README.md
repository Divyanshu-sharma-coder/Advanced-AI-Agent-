## 🚀 What is this project?

This project is an **Agentic AI-powered PyGame code generator and visualizer**.

You describe a visualization or game idea in plain English.  
The system will:

1️⃣ **Reason deeply** using **DeepSeek R1**  
2️⃣ **Extract executable PyGame code** using an OpenAI-powered agent  
3️⃣ **Display the generated code** inside a Streamlit UI  
4️⃣ **Automatically open Trinket.io**, paste the code, and run it visually using browser agents  

⚡ No boilerplate. No manual setup. Just idea → visualization.
